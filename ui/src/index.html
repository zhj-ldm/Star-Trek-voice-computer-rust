    模型

    每条配置是一套 OpenAI 兼容端点 + 模型 + Key（如「主 API」「模型 2」…）。切换后立即保存并生效，对话界面底部也可直接切换。

    多个 API Key 会按 round-robin 分摊，各自遵守 RPM 限速；本地 Ollama 可留空 Key，关闭思考时自动使用 -nothink 变体。

    语音

    Edge 音色/语速仅在提供方为 Edge 时生效；本地音色/语速仅在提供方为本地 Kokoro 时生效。本地语速范围 0.5～2.0。本地模型随安装包附带，无需联网。

    「静默结束秒数」：识别到人声后，静默多久算说完并发送（默认 1.5）。「无人说话等待秒数」：压根没人开口时最多等多久就停止、回到监听状态（默认 4）。「多轮静默秒数」：连续对话模式每句的静默结束阈值。「多轮最长录音秒数」：连续模式单轮最长录音。「多轮静默退出轮数」：连续多少轮没人说话自动退出。

    行为

    渐进式：常用工具常驻，其余通过 ToolGuide 清单按需启用，提示词更短、响应更快；默认全部加载：所有工具一开始就提供给模型。

    开启后：仅最近 N 条原文 + 再往前 M 条压缩摘要进入上下文，更早记录不再自动发送；AI 需要旧细节时会调用 RecallHistory 工具回溯。该工具在所有模式下都可用。
