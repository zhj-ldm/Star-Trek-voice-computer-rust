# 个人日志系统（personal-journal）

依托本机「星际迷航语音电脑系统」（voice-serve，默认 `127.0.0.1:8420`）运行的日志记录技能。
开启后**复用主程序的常驻麦克风采集**（不另开第二路麦克风），一直录到你让它结束：

- 整个「开启 → 结束」只产出**一个音频文件**（语音片段首尾相接累积，静音不落盘）；
- 后台自动按语句转写，结果追加到与音频**同名的 md**；
- AI 播报（TTS）的声音也会被录进同一个文件；
- 同时开放内置的语音转文字（STT）与唤醒词（KWS）能力供本技能调用。

## 播报规范（最重要，必须严格遵守）

开启与结束**只播报下面这一句，禁止任何多余的话**——不要汇报状态、目录、段数、路径，不要说“好的”“已为你开启”“从现在开始我会……”，不要加解释、不要加客套。

- **开启**：只播报 `Personal Log, Stardate <今日日期>`
  - `<今日日期>` 用当天日期，形如 `2026.10.4`（年.月.日）。
  - 示例：`Personal Log, Stardate 2026.10.4`
- **结束**：只播报 `已结束`

即：开启 → 一句话；结束 → 两个字。此外不输出任何内容。

## 环境要求

- 可执行文件：`journal`（本技能目录内，Rust 单二进制）
- 依赖：本机 voice-serve 语音服务处于运行状态（由 App 自动拉起，端口 8420）
- 存储根目录配置：本目录 `config.json` 的 `root` 字段（AI 可用 `journal dir <路径>` 修改，用户也可直接编辑该文件）
- 默认根目录：`~/Documents/个人日志`

## 存储结构

```
<根目录>/<YYYY-MM-DD>/
├── audio/<会话开始时间 HH-MM-SS>.wav   # 整场一个文件：只含有人声的片段，静音不入盘
└── text/<会话开始时间 HH-MM-SS>.md     # 同名转写文本，按时间戳逐条追加
```

> 注：静音被略去，因此音频里的时间轴与墙上时钟不严格对应；md 中的时间戳可作参考。

## 命令速查

```bash
cd /Users/zhj/Desktop/skill/personal-journal
BIN=./journal

$BIN start                         # 开启个人日志系统（一直录到你结束）
$BIN stop                          # 结束个人日志系统（收尾并等待转写落盘）
$BIN status                        # 查看运行状态 / 当前会话文件 / 今日目录 / 段数与最近文本
$BIN dir                           # 查看当前存储根目录
$BIN dir "/path/to/dir"            # 修改存储根目录（写回 config.json 并即时生效）
$BIN write "文本内容" --title "标题"  # 把 Markdown 写进当日 text 目录，返回文件绝对路径
$BIN stt /path/to/a.wav            # 内置语音转文字（对已有 wav）
$BIN stt-live 30                   # 录一段实时语音并转文字（默认上限 30s）
$BIN kws /path/to/a.wav            # 内置唤醒词检测（对已有 wav）
```

## 执行要点（默认走最短路径）

1. 用户说“开启个人日志系统 / 打开日志 / 开始记录” → 执行 `$BIN start`，然后**只**播报
   `Personal Log, Stardate <今日日期>`，随后回到监听。开启后无需再手动做任何事：会一直录、自动转写。
   **不要**把命令返回的目录、状态或任何说明念出来。
2. 用户说“结束个人日志系统 / 停止记录” → 执行 `$BIN stop`，然后**只**播报 `已结束`。
3. 用户要求更换存储位置 → `$BIN dir "<新路径>"`，简短告知已切换（一句话内）。
4. 用户要求“把这段内容记到今天的日志 / 输出成 Markdown” → `$BIN write "内容" [--title "标题"]`，
   简短确认“已记录”即可，不要念路径。
5. 用户要求把某段音频转成文字 → `$BIN stt "<wav路径>"`。
6. 只在用户明确表达上述意图时才开启/结束日志，不要擅自开启持续录音。

## 典型示例

```bash
# 用户：“开启个人日志系统”
./journal start          # → journal on: /Users/zhj/Documents/个人日志
# 播报（只此一句）：Personal Log, Stardate 2026.10.4

# 用户：“结束个人日志系统”
./journal stop           # → journal off
# 播报（只此两字）：已结束

# 用户：“把日志存到移动硬盘的 Journal 文件夹”
./journal dir "/Volumes/Disk/Journal"

# 用户：“把今天的会议要点记到日志里：xxx”
./journal write "会议要点：xxx" --title "会议要点"
```

## 边界与注意

- 依赖主程序语音服务；若报“voice-serve 是否在运行”，说明 App 未启动或语音服务未就绪，提示用户启动 App。
- 不提供搜索能力（搜索只由主 Agent 完成）。
- 整场只有一个音频文件：中途的静音不入盘，但语音不会因此被切成多个文件。
- 已开启时再次 `start` 会开启新的会话文件；`stop` 会自动收尾并等待转写写完。
- 若整场没有任何语音，不会留下空文件（自动清理）。
- 日志开关不影响唤醒词/打断等主链路功能（共用同一路麦克风采集）。
